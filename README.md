# Sunny Weds Dipti — Wedding Invitation Website

A responsive, single-page wedding invitation inspired by the physical cards:
- Deep maroon / antique gold palette
- Warm ivory backgrounds and dusty rose floral accents
- Elegant script and serif typography
- Card wording and event details carried into the website
- Responsive layout, countdown, and Google Maps search link

## Add the photos
Replace these two files with your own JPEG photos (keep the exact filenames):
- `assets/couple.jpeg` — Sunny and Dipti's photo
- `assets/joy.jpeg` — Joy's photo

The current files are visual placeholders. Your photos were not included in the card-reference uploads.

## Preview locally
Simply open `index.html` in a browser. No Node.js or build step is required.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this project.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.

The invitation date and venue text are in `index.html`; the countdown target is in `script.js`.
